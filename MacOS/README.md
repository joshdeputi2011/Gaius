# Gaius for macOS

Reserved for the SwiftUI/AppKit application, as requested. No macOS application is implemented in this iteration.

The intended native integration is a Swift wrapper around `Engine/native/include/gaius.h`, the v1 `.gaius` format in `Engine/schema`, and the same colors, spacing, and Fluent icon family in `Engine/design/tokens.json`. Each document will use a separate `NSDocument` window with a home launcher.
